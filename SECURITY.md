# Security policy

Security fixes target the latest published version. Adhan Desk is an early preview; reporting and fix timelines are not guaranteed.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting page](https://github.com/kamran-jabbar/adhan-desk/security/advisories/new). Include the affected version and operating system, reproduction steps, impact, and a minimal proof of concept. Remove credentials and personal information.

If private reporting is unavailable, open an issue asking for a private reporting channel without publishing vulnerability details. Do not put an exploitable report or sensitive files in a public bug report.

Relevant areas include the loopback audio server, IPC sender checks, external navigation, local file handling, and login startup. Ordinary timetable or playback failures belong in the bug report form unless they expose a security issue.
